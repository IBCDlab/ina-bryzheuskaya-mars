# Ina Bryzheuskaya Portfolio

## About the project
This is a personal portfolio website for Ina Bryzheuskaya, created as a final project for the Code the Dream Intro to Programming course. The site presents Ina’s background, experience, technical skills, and GitHub projects, and includes a contact form where visitors can leave a message.

## View project
https://ibcdlab.github.io/ina-bryzheuskaya-mars

## Tech stack
- **HTML5** for page structure and semantic layout.
- **CSS3** (including Flexbox, CSS Grid, and media queries) for responsive styling across mobile, tablet, and desktop.
- **Vanilla JavaScript** for DOM manipulation, handling the contact form, dynamically rendering skills, and fetching GitHub repositories via the GitHub API. 
- **Google Fonts** for custom typography.

## Project Structure

The project is organized into the following folders:

**/css** – contains all styles for the website  
**/js** – contains JavaScript files responsible for DOM manipulation and dynamic functionality  
**/images** – stores images used in the portfolio  
**index.html** – the main HTML file that structures the webpage

## How to run
1. Clone this repository to your local machine: git clone https://github.com/IBCDlab/ina-bryzheuskaya-mars.

2. Navigate to the project folder.

3. Open `index.html` in your browser. You can also run the project using Live Server in VS Code.
Ensure the `css`, `js`, and `images` folders remain in the same structure as in the repository so that styles, scripts, and images load correctly.
