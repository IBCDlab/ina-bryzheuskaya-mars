# Ina Bryzheuskaya Portfolio

## About the project
This is a personal portfolio website for Ina Bryzheuskaya, created as a final project for the Code the Dream Intro to Programming course. [page:1]   The site presents Ina’s background, experience, technical skills, and GitHub projects, and includes a contact form where visitors can leave a message. [page:1]   
## Tech stack
- HTML5 for page structure and semantic layout. [page:1]   - CSS3 (including Flexbox, CSS Grid, and media queries) for responsive styling across mobile, tablet, and desktop. [page:1]   - Vanilla JavaScript for DOM manipulation, handling the contact form, dynamically rendering skills, and fetching GitHub repositories via the GitHub API. [page:1]   - Google Fonts for custom typography. [page:1]   
## How to run
1. Clone this repository to your local machine.   2. Open `index.html` in your browser (you can double‑click the file or open it via a local server such as Live Server in VS Code). [page:1]   3. Ensure the `css`, `js`, and `images` folders remain in the same structure as in the repository so that styles, scripts, and images load correctly. [page:1]
